# Transit room example packages

Generated by `blueprints/generate_witb_packages_templated.py` for the Stairs.

- `stairs.yaml` — Transit Room v2 core package (`blueprints/automation/witb_transit_room/v2/rooms.yaml`).
  Provides `input_boolean.stairs_occupied`, override/force/manual booleans, `input_datetime.stairs_last_motion`,
  `timer.stairs_failsafe`, `input_number.stairs_failsafe_timeout` and `binary_sensor.stairs_occupied_effective`
  (plus Override Active, Clear Blocked, Failsafe Active).
- `stairs_actions.yaml` — WITB Actions V3 helpers for the Stairs, lights only (`rooms_stairs_actions.example.yaml`).

Load with `homeassistant: packages: !include_dir_merge_named packages/`. Package keys (`stairs_witb`,
`stairs_witb_actions`) must be unique across your packages. input_number helpers are generated without
`initial`, so set their values (for example the failsafe timeout) in the UI after the first load, or leave
the timeout helper unset in the blueprint and use the `failsafe_minutes` slider.
